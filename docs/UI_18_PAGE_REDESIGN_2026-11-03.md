# 18 页桌面界面改版

日期：2026-11-03。分支：`codex/v2-document-repository`。
参考：用户提供的 `sansuo_ui_redesign_18_pages.zip`，18 张 1440×900 PNG。

## 设计与实现

沿用参考图的深绿侧栏、荧光绿主按钮、浅绿灰背景、白色卡片和简洁表格，优先桌面端。保留现有 API、授权和操作语义；没有复制参考图的样例业务数据。

公共导航增加页面搜索与面包屑，保留当前知识库和主题切换。新增 `OverviewStats` 与 `styles/redesign.css`，页面布局使用现有 Semi UI 组件。完成状态的 `succeeded` 统一为绿色。

平台知识库 ID 仍由服务端生成并可复制；用户可填写的是 **Dify 知识库 ID（Dataset ID）** 和 **Dify 知识库 API Key**。组织、Embedding 和解析器仍只在管理员表单显示，继续使用上一批的后端权限限制。

## 真实数据与参考差异

- 没有时间序列接口的地方使用当前文档数量分布、累计请求分布，未绘制虚构增长曲线。
- 缺失值显示“—”或“未采集”；分页统计标明本页/当前列表。
- 没有实现的通知、忘记密码等按钮没有仿造。
- 问答侧栏只展示返回的执行事件，不生成或冒充模型思考过程。
- 本次未修改 Agent 核心、检索算法、数据库或外部知识库。

## 视觉复核

依据 oil-ui 做了一轮独立存量界面评审，不打分。修正角色选择框过窄、文件名截断、完成状态颜色不一致；删改监控/权限/组织页面向开发者的解释文案。主 Agent 另修正旧 CSS 导致的标题缩小、登录栏未铺满及按钮焦点对比度。

保留深绿导航、明亮主操作和轻描边卡片。动效仅采用 180ms 页面/卡片入场与轻微按钮反馈，并支持减少动态效果偏好。
