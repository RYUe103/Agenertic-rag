# 100 道真实问题引用质量评测（2026-11-01）

## 结论

本次完成 100 道原始 TAT-DQA test 问题的真实模型调用，没有生成替代题、筛掉失败题或给回答 Agent 提供标准答案。64 题最终通过引用技术校验，其中 51 题依赖引用修复；60 题引用命中基准来源文档。当前系统的引用身份验证已有作用，但预算消耗、错误来源/表格、计算工具参数和语义支持仍是明显瓶颈，不能称为高可靠问答验收通过。

证据支持采用同一模型辅助审查，**不是人工标注或答案准确率**。成功审查的 56 题中，49 题被判为完整支持；观察到裁判误判和标准题内部冲突，必须保留这一限制。

## 样本与执行范围

- 冻结使用第二阶段基准 `LOCAL_SEARCH_BENCHMARK_2026-10-31.json` 中原先选定的 100 题，来自 TAT-DQA test metadata，题干不变。不是随机代表性抽样。
- 100 题涉及 24 份目标文档；实际检索范围为 100 份已有 PDF 对应的文档，包含干扰文档，没有向 Agent 提供目标文档 ID。
- 64 题的目标文档使用已有 MinerU Markdown，36 题使用已有 PyMuPDF 冻结文本。原 PDF SHA-256 和文本哈希已核对。本次没有重新解析全部 PDF，不能视为完整 MinerU 入库验收。
- 实际调用现有 `qwen-plus`，运行 ReAct + ToolNode 和 8 个高层工具。标准来源、答案和上下文仅用于事后统计，不提供给回答 Agent 或裁判。
- 隔离知识库 `citation-evaluation` 使用本地 Tantivy、精确检索和 Repository 读取；未配置 Dify Vector。**本次不验证真实向量/Hybrid 召回率**，不修改生产知识库。
- 参数固定：工具调用 8 次、检索 4 轮、迭代 12 次、工具 60 秒、总时限 300 秒、上下文 80,000 字符、工具输出 24,000 字符、证据 12 条、总 token 预算 120,000、单次完成预算 2,000、连续工具失败上限 3、引用修复开启。并发度 2。
- 被测代码基线：`c554386d4eb284873c68798ff19c737f1cc17c95`，引用实现提交 `35dd3ac24ce88956b2c9ce4493f51c5859e9d4fe`。本次仅添加评测脚本、测试和报告，没有修改主 Agent 或检索实现。

## 可复核案例与指标局限

1. `tatqa_test_9073`：问题针对晶圆销售 Others 类别变化，Agent 却引用其他制程分类表并据合计 100% 判断不存在 Others。技术引用通过，但来源不命中，语义无保障。
2. `tatqa_test_9085`：问题针对 ACI Worldwide 薪酬变化，回答使用其他来源的股份薪酬数值。技术引用通过，不代表公司、指标和年份正确。
3. `tatqa_test_9101`：问题针对 American Tower 调整 EBITDA 中的 other expense/income，回答使用汇兑损失。来源及指标均需区分。
4. `tatqa_test_9157` 也没有引用基准目标文档。以上四题是“有引用但完全未命中标准来源”的全部题号；另有一题同时引用正确与非目标文档。
5. `tatqa_test_9075`：模型裁判判 unsupported，但表格的五项 FY19 工资 1,000,000、650,000、440,000、450,000、600,000 平均为 628,000，与回答和标准值一致。这是裁判误判案例；未篡改其自动 verdict。Agent 没调用 calculate。
6. `tatqa_test_9076`：题干明确写 390,000 → 450,000，回答 15.38% 符合该算式；标准答案 12.82% 对应脚注中的 390,000 → 440,000。题干/表格与脚注存在冲突。保留 partial 裁判结果，不强行把标准答案字面命中作为正确性裁决。Agent 没调用 calculate。

引用同一文档也可能定位到错误表格；命中标准文档只是必要的诊断维度。同模型裁判存在相关性偏差，本报告只对上述少量案例进行人工式核对，没有宣称完成 100 题人工评审。

## 裁判引用见证统一复核

裁判必须为 supported/partial 提供属于该 claim 所引用证据的原文见证。早期逐字检查会拒绝把 HTML 表格输出为纯文本的引文。最终对全部保存的裁判响应统一离线复核，允许原始连续子串或 HTML 文本提取后空白归一化的连续子串；不允许模糊匹配、改变数值或引用别的 claim 的来源。

此次离线复核不调用模型，不改变 verdict，不改变 Agent 的权限/引用校验。33 个见证使用了展示文本归一化；裁判失败由执行记录中的 16 个降为 8 个。执行记录包含早期原文检查和后续归一化检查两个版本，因此 JSON 字段使用 `original_execution_summary`，不能将其称为统一严格规则下的比较实验。原始记录完整保留。

## SQLite 启动异常与恢复说明

初始共享执行数据库批次中，22 题正常执行，78 题在模型执行前遇到 sqlite3.OperationalError。检查表明这 78 个 thread 均为 new 且没有任何 checkpoint。保留原始报告和异常记录，仅重试这 78 题，为每题使用独立执行数据库；22 个已完成题未重新执行。

初次异常未保存精确 SQLite 错误消息/代码，不能认定已证明是锁竞争。数据库 quick_check 正常，后续 saver 并发探针也未复现。恢复批次没有再次出现该启动异常；这只保证本次评测继续，**不意味着生产共享 SQLite 并发问题已经修复或验收通过**。后续重试脚本要求确认线程从未开始，拒绝凭缺少结果文件重放请求。
